5b · 裁定
· 源 2v:帧是一个 sandbox <iframe> —— 不执行脚本、不发网络请求、没有链接、没有图片、点不出任何东西,唯一交互是 <details> 折叠(移动端那一行给到 44 命中)。帧上没有工具栏(没有标题栏 / 全屏 / 复制 / 新窗口 / 刷新),帧里点什么都不会发消息。
· 宽高:帧宽 = 正文宽 358(390 − 左右 16);高由模型在开围栏行声明,移动端夹到 160–360(桌面 480),缺省 320。竖向超高在帧内滚。
· 横滚规则:帧内若有比 358 宽的内容(如那条 420 宽的耗时轴、宽表),在帧内横滚,页面不横滚 —— 与 4d / 4y 的 payload 盒、宽表同一条裁定(overflow-x:auto + 定宽内容 + 右缘裁切)。帧本身不做横向缩放,也不整体缩放内容。
· 骨架条件:开围栏行一到,高度就定了 → 按那个高度立住的帧框骨架(三条 r4 #eeeeee 条 + omPulseBg 一处锚点);围栏闭合前不变、不做渐进渲染;闭合后原位换成帧、不跳版、不做动画。
· 回落:写坏 / 超 16 KB → 普通代码块(语言标签 xray-html),没有错误提示;移动端唯一增量 = 代码正文 white-space:pre + 横滚(照 4d 的 INPUT / RESULT 盒),不折行。
· 帧内配色 = 站点主题变量,随主题切换;字号与行高照搬桌面帧(标题 15/600、正文 13/1.7、mono 11–12),不因移动端放大 —— 它是正文的延伸,和周围 15/1.75 的助手正文属于同一版式家族。
· 位置② = 最后一段正文之后;每轮最多两个组件(可一首一尾,也可同在一处)。组件不进折叠行,Timeline 里没有组件事件。

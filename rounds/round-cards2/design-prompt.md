## 提示词正文(从这里开始复制)

在项目里**新建两份画板集**:`Agent X-Ray Cards 2`(桌面 `2u`、`2v`)与 `Agent X-Ray Mobile - Runtime 2`(移动 `5a`、`5b`)。

**先读一遍现有画板再动手**:`1a`(工作台主屏:会话区的节奏、用户气泡、助手正文、工具卡、底部输入区)、`2c`(markdown 排版:表格 / 列表 / 代码块的既有画法)、
`2l` / `2m`(一轮完成后的折叠行与卡片展开体)、`2s` / `2t`(**R-CARDS 六种信息卡的外框、标题行、卡底、骨架、回落**,本轮两种新卡就长在这套语汇上)、
`2i`(骨架语汇)、`4c` / `4y` / `4z`(移动会话区与移动端信息卡)、`4u`(移动端载体适配态,含键盘)。
新画板画的是**助手回复里的两类组件**:可回传的卡片(访客点一下就把答案发出去)与模型自己写的静态 HTML 组件(在一个沙箱帧里)。
**不新造视觉语言**:卡片的一切从 `2s` / `2t` 取;帧的外框从工具卡展开体 / 代码块外框取;骨架从 `2i` 取;访客气泡照 `1a`。

### 0. 这是什么

**Agent X-Ray** 是一个已投产的站:访客与 AI agent 对话,右侧像 DevTools 一样实时看 agent loop 的内核轨迹。
助手回复是完整 markdown,R-CARDS 之后可以在正文里嵌**信息卡片**(六种,见 `2s`)。

本轮加两件事:

**A · 两种可回传卡片**(仍是 ` ```xray-card ` 围栏 + JSON,新增两种 `kind`):

| kind | 用途 | 主体 | 回传 |
|---|---|---|---|
| `choice` 单选 | 让访客在 2–8 个选项里选一个 | 可选题干一行(次级色)+ 选项行(每行:单选圆点 + label + 可选一行 note 次级色) | **没有按钮**;点任一选项 → 立刻发出一条访客消息「题干: 该选项」→ 卡锁定 |
| `choice` 多选 | 让访客选若干个 | 同上,指示改勾选框 | 卡底一枚 **submit 按钮**(缺省文案「提交」),**至少选中一项前禁用**;点了发出「题干: 选项、选项」→ 卡锁定 |
| `form` | 让访客填 1–5 项信息 | 可选题干 + 字段列表(每个:label + 输入框或下拉;必填有小字标记) | 卡底一枚 **submit 按钮**(缺省「提交」),**必填未填前禁用**;点了发出「题干 字段: 值; 字段: 值」→ 卡锁定 |

发出去的就是一条**普通访客消息**:用户气泡照 `1a`,文本就是上面那句话,没有任何「来自卡片」的标记;随后 agent 照常开始下一轮(发送按钮转圈、Timeline 扫光)。
**锁定态**:选项 / 输入框不可再点,已选高亮保留,按钮禁用,文案不变。
**一轮生成中(busy)**:卡上的选项与按钮和底部发送按钮一样禁用(同一副禁用视觉)。

**B · 静态 HTML 组件**(新围栏 ` ```xray-html `):模型写 HTML + CSS,会话区放进一个沙箱 `<iframe>`:

- **宽 = 正文宽**(桌面会话区正文宽;移动 358),**高由模型声明**、夹到 160–480(移动 ≤ 360),缺省 320;内容超高在**帧内**滚。
- 帧里**不执行脚本、不发任何网络请求、没有链接、没有图片、点不出任何东西**;只有排版(标题 / 段落 / 表格 / 列表 / 代码 / 内联 SVG / `<details>` 折叠)。
- 帧内文字与配色**跟随站点主题**(帧里注入了站点的颜色 / 字体变量),看起来像正文的一部分,只是被一圈边框圈起来。
- 流式期间:开围栏行一到,帧的高度就定了 → 先显示**按那个高度立住的骨架**;围栏闭合 → 换成帧;不做渐进渲染。
- 写坏了 / 超过 16 KB → **回落成普通代码块**(语言标签 `xray-html`),没有错误提示。

### 1. 设计时只能用这些数据(别画出拿不到的信息)

- `choice`:可选 `title`(≤ 60)、可选 `prompt`(题干,≤ 200)、`multiple`(真 / 假)、2–8 个 `options`(`label` ≤ 60,可选 `note` ≤ 200)、
  多选时可选按钮文案(≤ 20,缺省「提交」)。**选中态与锁定态是本地状态**,刷新回初始态(老卡又能点)。
- `form`:可选 `title` / `prompt`、1–5 个 `fields`(`label` ≤ 40;`type` 只有 `text` 与 `select` 两种;可选 `placeholder` ≤ 100;`select` 有 2–8 个选项;`required` 真 / 假)、可选按钮文案。
  text 输入最多 100 字。**没有**:校验错误文案、数字 / 日期 / 多行输入、上传、步骤条、「已发送」字样。
- 发出的消息文本**只由**题干 / 所选 label / 字段 label / 访客填的值拼成;`title` / `note` / `placeholder` / 按钮文案都不进消息。
- HTML 组件:**只有**帧高与帧内内容;帧上**没有**标题栏、没有「全屏」「复制」「在新窗口打开」「刷新」按钮,没有加载失败态(失败 = 代码块)。
- 位置:组件在最终回答**首**或**末**,每轮最多两个。
- **不存在**:图片、图表库、图标、进度条、颜色语义、帧内脚本交互、帧内链接、「发送成功」提示、撤回、Timeline 里的组件事件、访客气泡上的来源标记。

### 2. 三条硬约束

1. **不新造视觉语言**:卡片照 `2s` / `2t`(r6、`rgba(0,0,0,.03)` 底、1px `#e0e0e0` 中性描边、标题行 mono 10/600 `#9ca3af` 0.08em、卡底 ghost 按钮);
   帧外框照工具卡展开体 / 代码块外框(r6–r7 + 1px `#e0e0e0`),帧内容不另画外框;选择指示(单选圆点 / 多选方框)用 1px `#e0e0e0` 描边、选中态品牌色;
   输入框与下拉用站内既有输入框语汇(`1a` 底部输入框那一枚缩小版:1px 描边、r7、13px);访客气泡照 `1a`。
2. **画板上没有的功能不画**:没有错误提示、没有「已发送」字样、没有撤回、没有帧工具栏、没有帧内链接 / 图片 / 按钮。
3. **动效只能从现有三个里选或不用**:骨架用 `omPulseBg`;选中 / 禁用 / 锁定切换、帧换入都**不做动画**;发送后的下一轮照 `1a` 既有的转圈与扫光。

### 画板 `2u` —— 桌面 · 两种可回传卡 + 位置① + 发送

以 `1a` 为底(三栏照抄),中栏画**两轮**:

- **第 N 轮(已完成,折叠行收起,`2l` 画法)**:折叠行**紧接着**是一张 `choice` **单选**卡(位置①),再是两三段最终正文。卡画成**已发送锁定态**:
  四个选项里第二项圆点高亮、其余灰、整卡不可点(内容要像 agent 会写的:比如题干「你更想从哪条线入手?」,四个选项 = 本站四组工具,note 各一句)。
- **紧随其后的访客气泡**:文本就是那句被发出去的话,例:`你更想从哪条线入手?: 沙箱执行组`(题干 + ASCII 冒号空格 + 所选 label);气泡照 `1a`,**没有任何来源标记**。
- **第 N+1 轮(进行中)**:发送按钮转圈、Timeline 末行扫光、助手正文刚出两行 —— 证明点选项之后就是一轮普通对话。

主体之外开一块**标本区**(同一画板,右侧或下方,注释标明「标本,不在会话流里」),逐项画出:

1. `choice` **单选未发送态**:全部选项可点、无按钮、无高亮(与主体里的锁定态成对)。
2. `choice` **多选**卡,**一项都没选、按钮禁用**(勾选框空、按钮文字 `#9ca3af`,文案「提交」)。
3. `choice` 多选卡,**选中两项、按钮可用**。
4. 同一张多选卡的**锁定态**(两项勾选保留、其余灰、按钮禁用、文案仍是「提交」),旁边一条访客气泡 `…: 外呼组、沙箱执行组`。
5. `form` 卡,3 个字段(text / select / text),其中一个 `required` **未填、按钮禁用**;`select` 画成未展开的下拉(值为 placeholder 次级色);必填标记用次级色小字。
6. 同一张 `form` 卡,**全填、按钮可用**;再画它的**锁定态** + 访客气泡 `帮我定制学习路径 经验: 3 年; 目标: 上线一个 agent 站; 每周时间: 5 小时`(题干 + 空格 + `字段: 值` 以 `; ` 相连,全部 ASCII 标点)。
7. **busy 态**:一张未发送的单选卡在「上一轮还在生成中」时的样子 —— 选项禁用视觉与底部发送按钮转圈同框。
8. 一张 `choice` 卡的**流式骨架**(与 `2t` 的卡片骨架同一画法,不必另想)。

每张卡宽度 = 会话区正文宽。画板注释写清:两种新 kind 的解剖与上限(选项 2–8 / 字段 1–5 / 字数)、**单选点即发、多选与表单 submit 发**、按钮禁用的条件、
消息文本的组成规则(题干 + `: ` + 选项以「、」相连;表单是单行 `字段: 值; 字段: 值`)、**发出的字都是卡上看得见的字**、锁定态与 busy 态、
**每轮最多两个组件**、位置①的定义(折叠行之后、正文之前)、刷新后回初始态(老卡又能点)。

### 画板 `5a` —— 移动 · 两种可回传卡

## 提示词正文(从这里开始复制)

在现有画板集 `Agent Runtime Workbench` 里**追加两块新画板**,编号 `2l`、`2m`。

**先读一遍现有画板再动手**:`1a`(工作台主屏 · Timeline)、`1b`(事件详情展开)。
新画板画的是 `1a` 中栏会话区**同一段对话在这一轮跑完之后**的样子,必须与 `1a` 同一套骨架、
同一套 token,**不新造任何视觉语言**。左栏会话列表、顶栏、右栏运行时面板全部照抄 `1a`,
只有中栏会话区、输入栏的按钮状态、右栏 Timeline 末行的「进行中 / 已完成」不同。

### 背景:现在缺什么

`1a` 的会话区已经画了工具调用卡:助手一段话之后跟两张卡(绿色 `read_file {"path": "/etc/hosts"} 0.3s ˅`、
红色 `bash sudo sed -i '/legacy/d' /etc/hosts 0.1s ˅`),再接一段话。`1a` 的注释明确写了它画的是
**一轮还没跑完的时刻**(发送按钮在转圈、Timeline 末行在扫光)。

没画的有两件事:

1. **这一轮跑完之后,会话区长什么样。** 参考实现 pi-web 的做法:最终回答出来后,前面的处理过程
   (中间说的话 + 全部工具卡)收成一行「处理详情 · 8 条消息 · 10 次工具调用」,行首一个向右的箭头;
   最终回答单独留在这一行下面。点那一行,处理过程在原位展开。我们要的就是这个行为。
2. **每张卡右侧那个箭头点开是什么。** 现在只画了收起态。

### 词汇(画板注释里请统一用这一套)

- **一轮**:访客发一条消息 → agent 给出最终回答。
- **模型往返**:一轮里 agent 每调一次模型算一次;右栏 Timeline 里的 `Turn 1` / `Turn 2` 就是它。
  `1a` 这段对话是**一轮、两次往返**。
- **工具调用**:一张卡。
- **最终回答**:一轮里最后一次模型往返产出的那段话;它前面的所有话与卡统称**处理过程**。

### 折叠行能显示的数据只有这些(设计时别写出拿不到的信息)

- 模型往返次数、工具调用次数
- 这一轮的总耗时(访客发出消息 → 最终回答结束)
- 是否有工具调用出错或被拦截(布尔)

每张卡能显示的:工具名、入参摘要(单行、已截断、已脱敏)、结果摘要(同上)、耗时、是否出错 / 被拦截。

**明确不许出现**(与站点既有裁定一致):模型名、provider 名、每段的 token 数与费用
(pi-web 有这些行,我们不要 —— 模型与 provider 是服务端配置,公开即泄配置面;token 与费用只在顶栏
统计条按会话汇总)、「思考」块(pi-web 有,本站的内核透明度由右栏承担,会话区不放)。

### 三条硬约束

1. **不新造视觉语言**:颜色、圆角、字号、间距、字体全部取自下面的 token 表。卡片本身的解剖
   (左:工具名 mono 12/600;中:摘要 mono 11 弱化色、单行省略;右:耗时 11px tabular;末:12px 箭头)
   与 `1a` **一字不差**。
2. **折叠行是一行,不是卡片**:它是导航,不是内容。字号层级不得高于正文;颜色用次级 `#6b7280`
   或弱化 `#9ca3af`;箭头与卡片上的是同一个图标(向右 = 收起、向下 = 展开)。
3. **动效只能从现有三个里选或不用**:`omPulseBg` / `omWaveSweep` / `omSpin`。展开 / 收起不需要动画,直接切换。

### 现有 design token(照抄,勿改)

- 画布:`#ffffff` 底 / `#f5f5f5` 面板 / `#eeeeee` hover / `#e8e8e8` 选中 / `1px #e0e0e0` 边框
- 文字:`#1a1a1a` 正文 / `#6b7280` 次级 / `#9ca3af` 弱化;品牌色 `#2563eb`(hover `#1d4ed8`)
- 语义:成功 `#16a34a` + `rgba(34,197,94,.04/.25)` 淡染;错误 `#ef4444` + `rgba(248,113,113,.05/.3)` 淡染
- 工具卡(`1a` 原样):圆角 7、内边距 `7px 10px`、项间距 8;成功态 = 成功色字 + `.04` 底 + `.25` 边;
  错误态 = 错误色字 + `.05` 底 + `.3` 边
- 会话区:正文 14px / 行高 1.7;用户气泡 `#eff6ff` 底 + `rgba(59,130,246,.2)` 边、圆角 12、最大宽 85%;
  项与项之间 14
- 行内代码:mono 12、`rgba(0,0,0,.03)` 底、圆角 4、内边距 `1px 5px`
- 小标题(如 `INSTALL` / `FILES`):mono 10px/600 `#9ca3af`、字距 0.08em
- 圆角:4 微徽标 / 5 小按钮 / 6–7 卡片 / 8 弹层 / 12 用户气泡;等宽字体 JetBrains Mono
- 顶部导航条:高 44、四格(Runtime · Notes · Skills · About),两块新画板都要带上,与 `1a` 一致

### 画板 `2l` —— 会话区 · 一轮已完成(折叠态)

同一段对话,时间往后拨到这一轮跑完:

- 用户气泡不变
- 紧接着一行**折叠行**。示例文案(措辞你定,信息量别多于上面列的那几项):
  `处理详情 · 2 次模型往返 · 2 次工具调用 · 0.4s`,行首箭头向右。
  这一轮里 `bash` 那次被拦截了,所以折叠行上要有一个**不靠读字也能看出「里面有一次没成功」**的标记
  (比如一个 `#ef4444` 的 6px 圆点,放哪你定)—— 但它只是提示,不是警告条
- 折叠行下面是**最终回答**:`1a` 里那段「这条命令被 permission-gate 拦截了……」写完整
  (补一两句手动修改建议即可,别写长)
- 输入栏恢复常态:发送按钮不转圈、可点(与 `1a` 的转圈禁用态相对)
- 右栏 Timeline:`Turn 2` 的末行不再扫光,收在 `message_end` / `turn_end`;其余照 `1a`

请在画板上标注三条规则:

- 一轮里**没有任何工具调用**时**不出现折叠行**,会话区与今天完全一样(只有用户气泡 + 回答)
- 一轮**还在进行中**时**不折叠**,就是 `1a` 那样卡片内联;折叠只在最终回答结束的那一刻发生一次
- 最终回答为空(模型以工具调用收尾、之后没再说话)时**只剩折叠行**,下面不留空段

### 画板 `2m` —— 会话区 · 折叠行展开 + 一张卡展开

在 `2l` 的基础上点开:

- 折叠行箭头向下,行本身留在原位当作这一段的标题
- 其下按原顺序展开处理过程:「我需要先看一下当前的 hosts 文件内容。」→ `read_file` 卡 → `bash` 卡。
  展开区与下面的最终回答之间要能看出边界(左侧一条 `#e0e0e0` 竖线做缩进、或只靠间距 —— 你定并标注)
- `bash` 这张卡**再点开它自己的箭头**(向下):卡片下方接一个**展开体**,两段 mono 11 文本 ——
  `INPUT`:`sudo sed -i '/legacy/d' /etc/hosts`;
  `RESULT`:`permission-gate: blocked — matches rule "sudo sed on system file"`
  (错误态用错误色描边或字色,你定)。两段各自有高度上限(建议 6 行),超出的部分尾随 `…(已截断)`,
  **不做内部滚动**
- `read_file` 卡保持收起,证明两张卡的展开互不影响
- 小标题 `INPUT` / `RESULT` 用现有小标题语汇(mono 10/600 `#9ca3af` 0.08em),不新造

### 可交互原型 `Agent X-Ray Prototype`

Runtime 屏的会话区目前是静态 HTML、演示的是进行中那一轮。请加两处交互:

1. 两张卡的箭头可点,切换各自的展开体(`2m` 的卡片展开态)
2. 左栏点第二个会话「帮我查上海→东京的低价航线」时,会话区切到一段**已完成**的对话:
   一句用户消息 + 折叠行(点击可展开,里面放 1–2 张 `notes_search` 之类的绿色卡)+ 最终回答。
   右栏 Timeline 换成一段已完成的轨迹(全部行不扫光)即可,不必精细

如果第 2 条你认为改动太大,只做第 1 条,并在画板上说明。
